## Cómo editar el perfil

1. Los textos están en `profile/README.md`. Los gráficos son SVG estáticos con texto real: se pueden abrir y editar con cualquier editor.
2. Cada gráfico tiene dos versiones (`-light` y `-dark`). Si cambiáis una, cambiad también la otra.
3. Nada de scripts, contadores de visitas ni servicios externos: GitHub los elimina o los bloquea, y no aportan.
4. Antes de añadir un proyecto a la sección «Proyectos», comprobad que el repositorio es público y funciona.
